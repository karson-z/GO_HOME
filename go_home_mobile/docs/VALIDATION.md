截图由应用的原生渲染目标读取，并非网页截图。人工检查修复了发光纹理缺失造成的方块及远景显隐/雾参数未随路线更新的问题。截图在外层 `artifacts/current-native/`，预览见本目录图片。

该测试使用检查点跳转和结尾时钟定位，**不是逐关连续手动通关录像**。没有用自动测试代替真机延迟和长期性能验收。

## 构建与交付

- `flutter analyze --no-pub`：无问题。
- Android：`flutter build apk --release --target-platform android-arm64`；最低 API 24 / 目标 API 36。检查 ARM64 ABI 和 APK 签名。当前为本地体验签名。
- iOS：`flutter build ios --release --no-codesign`，验证真机 ARM64 Release 可编译；不交付已签名 IPA。安装需使用自己的 Apple 开发团队签名。
- 源码 ZIP：本轮执行 ZIP 完整性和必需工程文件检查。完整参考资源和工具一并提供，常规运行无需这些工具；本轮未重复独立解压后的构建验收。
- 音频：原版采样器离线生成全部示范/七音；48 小节结尾共 2,160 个事件，无遗漏声部，立体声 48 kHz，生成报告包含每个音轨的时长、峰值与 RMS。AAC 输出不会逐采样等同于 WebAudio。
