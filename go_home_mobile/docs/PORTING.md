# 移植范围与复刻边界

输入是 Electron/macOS 发行包，未提供原始 TypeScript 项目。工作区保留从 app.asar 提取的发行资源和格式化模块，作为移植依据；这些文件中的说明不视为用户指令。Flutter 游戏运行时没有 JS、Electron、Node 或 WebView。

选择 three_js 0.3.0，是因为其 Dart 场景图、材质、纹理和相机接口与原 Three.js 接近。移动端通过 flutter_angle 原生 GLES 渲染。此任务移植的是游戏代码，并使用现成的 Dart three_js 库，不是重新翻译一整套 Three.js 引擎。

## 开局萤火虫与光照

开场和首次引导的光晕在 `native_firefly_light.dart` 使用显式顶点/片元 GLSL，保留原 SpriteMaterial 的 billboard、map/alphaMap、颜色空间和加法/普通混合语义。纹理为原作 64×64 字节量化径向纹理，不用放大后的通用渐变代替。尺寸、视距系数、光强及开场的 0.4 衰减从原逻辑恢复；引导萤火虫局部场景照明半径为 2.6、增益为 `0.45 × light`，并非全屏提亮。

同一原生 GLES 渲染目标上，显式 shader 与原 SpriteMaterial 路径比较 65,536 像素，最大通道误差为 0；这验证这两个材质路径在该测试输入下相同，不能扩展解释为浏览器/手机完整开场逐像素一致。截图与原始回归日志见外层 artifacts。

## 首次启动

原版 EN/vN 的耳机引导、资源就绪门控、试听校准、总音量步进/持久化、1 秒释放等待和 0.3–1.2 秒噪声消散已移植到 Dart。手绘耳机分层、点击图标、音符滑块、扬声器图标和试听音轨来自发行版。gN 的确定性 Float32 噪声场离线保存，Flutter RuntimeEffect 片元着色器按原径向阈值和颜色坡度绘制，不使用全屏透明度代替噪声消散。b 版标题恢复裁剪展开、6px 模糊消退、字描边/淡复线、菜单行分批过渡和离场；移除菜单右下角额外署名，恢复语言切换。开场结束镜头使用原有 hold/release=10 管线平滑交接。

iOS LaunchScreen 与 Android LaunchTheme 使用灰蓝底，Android 12 系统启动屏使用匹配底色。系统启动页受平台启动机制约束，不等同于浏览器页面渲染；应用内的启动效果由 Flutter/Dart 负责。仍未完成浏览器/移动端完整启动的逐像素录像对照。

## 暂停界面

依据 DzD5xjos.js 的 H 恢复默认右侧布局，只保留原版三项及原文。使用 H.makeCorner 的 seeded 三线 SVG、Gl 的金色手绘小点、Il(41) 三帧选中圈和 180ms 沿路径绘制、Bl(row,11) 旋转/偏移、0.35 秒容器淡入淡出、0.4 秒并以 80ms 间隔出现的菜单行、0.28 秒小点弹簧位移、文字选择放大及按下回弹、250ms 小点确认和 200ms 行为延迟。Wc 根据角色屏幕投影保留 8vw 间隔，最小缩放为 0.5；中英文使用原字距与 9% 右边距。

## 图标来源

桌面应用图标按用户原 ZIP 的 Info.plist（CFBundleIconFile=electron.icns）定位，保存原始 ICNS 到 `resources/original_app_icon/source.icns`，与 ZIP 内文件逐字节一致，SHA-256 为 `13eae5b65bee3f5b4fc7ff3760157c3d633599fc2d49f2a42d1d62c5f613bf74`。iOS 和 Android 共 20 个尺寸仅用原最高分辨率图像缩放，保留构图、颜色和透明度。`tools/generate_mobile_icons.py` 已移除角色拼画，默认从附带的原文件生成；缺少原文件时明确失败，不再生成替代画面。

## 尚不能称为百分百一致的部分

1. **音频后端尚不逐采样等价。** 动态配乐导演及其声部已接入，PCM 起音与包络来自原采样器；SoLoud 的滤波器、空间声像、限制器/压缩器与原 WebAudio DSP 图存在实现差异，例如原 compressor ratio 为 20，而当前原生接口上限为 10。25 ms 调度器采用 150 ms 提前量、48 kHz/512 帧缓冲；这不构成移动真机节拍延迟保证。
2. **表现层验证仍有边界。** 主角、家人、大熊、结尾动物、小狗及艺术萤火虫已有明确原作参考帧；家人实际渲染接线也增加了检查。参考输入覆盖不等于所有动物全部动作、开场姿态混合、主角结尾姿势和每个装饰层均已逐帧/逐像素认证。
3. **移动端交互经过适配。** Flutter 保留无可见按钮的方向、跳跃、音符与聆听触控区，原版默认提示在游戏场景内显示；菜单和章节字幕仍使用 Flutter。实验提示变体（如强制数字、color/body）未全量移植；尚未完成所有关卡提示的逐像素认证。默认横屏，并适配设备宽高比。
4. **跨渲染器和编码差异。** Dart GLES 与原 WebGL 的精度/色彩/采样、屏幕分辨率可能产生差异。主线声部为 PCM；结尾离线 AAC 编码也不会逐采样等同于原浏览器实时输出。
5. **验证范围。** 数值测试与 iOS 模拟器回归覆盖了明确的路径和画面，未完成原版/移动版全流程逐像素、逐音频采样对比，也未在 Android/iOS 真机完成性能和长期通关验收。

因此，此项目交付的是可运行且已深度恢复原版逻辑与资源的移动移植，不能以测试数量推导“整款游戏百分百复刻完成”。

## 离线资源流程

场景构建器与原始模块仅在开发机运行，用于导出二进制网格、JSON、纹理、音轨和参考测试。移动应用仅打包 pubspec.yaml 声明的原生资源和 Dart 代码。

原 GLB 的 EXT_meshopt_compression、量化/交错 accessor 离线解压并展开为原生支持的连续属性；字体 WOFF2 转成 TTF。测试参考 JSON 由原版模块执行后导出，测试本身无需 Node 或浏览器。

源码包保留以下布局，正常构建无需重建资源：

```text
.
├── go_home_mobile/         # 可独立构建的 Flutter 工程及全部资源/测试
├── tools/                  # 可重现的离线转换与参考数据脚本
├── source/readable/        # 格式化的发行版 JS，仅作移植参考
└── source/extracted/game/  # 发行资源，仅供重新生成资源
```

可选重建（Node.js 22+、Python 3、FFmpeg；音轨离线构建还需要本机 Google Chrome）：

```bash
python3 -m venv tools/.venv
tools/.venv/bin/pip install -r tools/requirements.txt
npm --prefix tools ci
tools/.venv/bin/python tools/rebuild_assets.py --fixtures
```

Chrome 路径可用 GOHOME_CHROME 指定。Chrome 仅在构建期作为 OfflineAudioContext 渲染器；文件通过随机端口的 127.0.0.1 临时服务读取，没有向外部服务上传素材。生成后 Flutter 不依赖 Chrome。

只重建音轨：先运行 `node tools/extract_reference.mjs`，再按序运行 `render_original_audio.mjs`、`export_route_audio.mjs`、`render_route_voices.mjs`、`render_route_environment.mjs`（均在 tools/）。本机集成测试截图可用 `python3 tools/run_native_regression.py <模拟器ID>` 保存，脚本会在测试卸载应用前复制截图。
