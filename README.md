# Go Home 移动版交付

Flutter 工程：`go_home_mobile/`。使用 Dart `three_js` 渲染，提供 iOS / Android 原生版本。

运行、操作、构建说明见 [工程 README](go_home_mobile/README.md)。移植差异见 [移植说明](go_home_mobile/docs/PORTING.md)，测试覆盖见 [验证记录](go_home_mobile/docs/VALIDATION.md)。

`tools/` 为原游戏素材的离线转换工具；工程已经带有转换后的资源，正常运行无需重新提取原包。

`artifacts/` 保存源码压缩包、Android ARM64 体验包、原生运行截图与构建清单。

当前交付包含连续主线、原生动态配乐导演、完整结尾及原作骨骼动作对照。开场萤火虫使用显式 GLSL，恢复原纹理、尺寸、衰减与局部照明半径。跨后端音频 DSP、移动触控布局、真机及全流程画面/音频认证仍有边界，不能标为已验证百分百一致。具体范围见工程文档。

本轮恢复原版默认场景提示，移除额外的移动键盘 HUD、方向按钮、旋律答案与操作说明；多点触控改为无可见按钮的区域输入。触控区域位置见工程 README。

首次启动已接入原版耳机引导、试听音量校准、噪声阈值雾幕、萤火虫入场与 b 版标题过渡；雾幕使用 Flutter 片元着色器，应用内不运行 JavaScript。校准结果会本地保存。

设置页已改为原版透明手绘布局，恢复三路音量、语言、三档画质、数字提示、侧边重新试音与返回；移除旧实色设置弹窗和系统控件。主菜单进入设置时保留标题。

暂停页按原版 H 恢复右侧“继续、设置、回到主菜单”三行、手绘选中圈与金色小点、纸纹侧雾和三线菜单入口，移除旧居中标题/章节与安全位置按钮。支持原版中英文、键盘选择及 200ms 确认，设置返回保留选中行。

iOS/Android 应用图标直接取自原包 `Go Home.app/Contents/Resources/electron.icns`，只转换尺寸；旧角色拼画脚本已替换为原资源导入器。游戏内已无 Material 图标，菜单入口、耳机、扬声器、滑块及树形图标使用原版矢量资源。
